申请入住

申请一个 pcb.pub 子域名，一次申请有效 5 年。每份申请都由人工审核，通过后为你添加解析。

申请前，请确认

  • 网站已经上线，并且有实际内容，不是空白页、占位页或纯跳转页面。
  • 网站托管在中国内地以外：可以是 GitHub Pages、Cloudflare Pages、Netlify、Vercel 等平台，也可以是你自己的云服务器。
  • 你已阅读并同意使用规则。

先查一查想要的名字能不能申请。查询会检查名称格式、保留名称和现有解析记录。

  • 只能使用小写字母 a～z、数字 0～9 和连字符 -。
  • 长度 3 位及以上，最多 32 位；不能以连字符开头或结尾，也不能连续使用两个连字符。

2选择解析方式

CNAME

适合托管平台

网站在托管平台上时选择。目标地址填平台提供给你的域名，例如 yourname.github.io、yourname.pages.dev。

A 记录（IPv4）

适合自有服务器

网站在自己的服务器上时选择。目标地址填服务器的公网 IPv4 地址，例如 203.0.113.10。服务器须位于中国内地以外，并且由你本人使用。

每个子域名只能二选一。暂不开放 MX、NS 等其他记录类型。

3让网站认得这个地址

  • 网站在托管平台上

    在平台的自定义域名设置里填写 yourname.pcb.pub。以 GitHub Pages 为例：仓库 Settings → Pages → Custom domain。开通前显示 DNS 检查未通过是正常的，解析生效后再开启 HTTPS。

  • 网站在自己的服务器上

    把 yourname.pcb.pub 加到 Web 服务器配置里，例如 Nginx 的 server_name。解析生效后，可以用 Let's Encrypt 等免费证书开启 HTTPS。

常见问题

收费吗？

完全免费，续期也免费。这是一个非营利项目。

子域名能用多久？

自开通之日起有效 5 年。到期前用原申请邮箱来信即可续期，每次续期 5 年；到期未续期的，我们会删除解析，名称重新开放申请。

怎么知道想要的名字能不能申请？

在本页第 1 步查询即可。查询会检查名称格式、保留名称和现有解析记录，但正在审核中的申请可能查不到；同一名称有多人申请时，按邮件到达先后处理，最终以审核回信为准。

需要备案吗？

子域名只能指向中国内地以外的服务器，这种情况下不需要备案。指向中国内地服务器的申请不予通过。

支持哪些解析类型？

支持 CNAME 和 A 记录（IPv4），每个子域名二选一。暂不开放 MX 邮件记录和 NS 委派。

能开启 Cloudflare 代理（小黄云）吗？

默认不开启。pcb.pub 的解析托管在 Cloudflare，子域名默认都设为“仅 DNS”，访客会直接访问你的托管平台或服务器，HTTPS 证书也由你那边签发。如有需要，且开启条件允许，则可以开启，请在邮件里说明。

“网站由你托管”是什么意思？

网站的文件和服务器由你自己负责：放在 GitHub Pages 这类托管平台上，或你自己的服务器上。pcb.pub 只提供子域名和解析，把访客指引到你的网站，不存放、也不代管任何网站内容。

选 CNAME 还是 A 记录？

网站在托管平台上，选 CNAME：平台的服务器 IP 可能变化，CNAME 会自动跟随。网站在自己的服务器上、有固定的公网 IPv4 地址，选 A 记录。

托管平台要求添加验证记录怎么办？

部分托管平台（如 GitLab Pages）要求添加一条 TXT 记录来验证域名归属。请在申请邮件里写明记录的名称和值，名称须在你的子域名之下，审核通过时一并添加。这类验证记录是 CNAME／A 记录之外唯一的例外。

服务器换了 IP 怎么办？

请用申请时的邮箱来信告诉我们新的 IP。停用服务器或释放 IP 前，也请来信删除解析，免得这个 IP 被别人接手后，你的子域名指向陌生的网站。

怎么修改或注销子域名？

请用申请时的邮箱来信，写明子域名和要做的修改。为确认是本人操作，我们只处理来自原申请邮箱的请求。

服务会一直可用吗？

这是个人维护的非营利服务，我们会尽力保持稳定，但不承诺永久可用。如需停止运营，会提前通过邮件通知所有站长。
